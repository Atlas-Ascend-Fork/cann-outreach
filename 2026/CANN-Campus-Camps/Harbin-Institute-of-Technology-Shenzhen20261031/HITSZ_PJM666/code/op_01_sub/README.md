## 算子实现介绍

本算子基于 Ascend C 实现矢量减法，对形状为 (8, 2048) 的输入张量逐元素计算 z = x - y，支持 float32 和 float16 数据类型。实现中将 16384 个元素划分为 64 个分块，每块包含 256 个元素，根据可用矢量核数量分配计算任务；各核使用 DataCopy 将输入数据从全局内存搬入片上局部内存，通过 TQue 队列同步数据搬运与计算，调用 AscendC::Sub 完成减法后，将结果写回全局内存。分块大小满足两种数据类型的内存对齐要求，且能够整除元素总数，无需处理尾块，启动函数根据输入数据类型选择对应的模板核函数。
