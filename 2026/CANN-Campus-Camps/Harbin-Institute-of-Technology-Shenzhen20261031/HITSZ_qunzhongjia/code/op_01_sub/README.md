## 算子实现介绍

使用 Ascend C 实现逐元素减法 z = x - y，支持 float32 和 float16。

将形状 (8, 2048) 的输入划分为 8 个数据块，每块 2048 个元素，根据可用向量核数量启动最多 8 核并行计算。每个核将输入搬入 UB，调用 Sub 完成减法，再将结果写回 GM；通过流水线事件同步保证搬运与计算顺序，数据块满足 32B 对齐要求。

已在 Ascend 910B 上编译运行通过，公开 float32 用例最大误差为 0；CANNJudge 提交 1053334，两个测试点全部 Pass。
