## 算子实现介绍

算子采用 8 核并行策略，每个 AI Core 负责处理一行连续的 2048 个元素。执行流程为：从全局内存读取 x 和 y 到 Unified Buffer，调用 AscendC::Sub 完成逐元素减法，再将结果写回全局内存。

为降低 UB 内存与队列调度开销，第五版使用 TQueBind&lt;VECIN, VECOUT&gt; 复用 y 的缓存空间：计算时原地执行 y = x - y，并将该缓冲区重标记为输出后直接搬运至 z。该设计减少了独立输出缓存的分配与队列传递，在保证计算正确性的前提下优化了内存复用效率。
