## 算子实现介绍

采用多核矢量计算实现减法算子，计算公式为 z = x - y。

支持 float32 和 float16 两种数据类型，输入张量形状为 (8, 2048)。

Tiling策略：将16384个元素划分为8个数据块，每个计算块处理2048个元素。每块数据量满足32B对齐要求。

计算流程：通过 DataCopy 将输入数据从 GM 搬运至 UB，使用 Ascend C 的 Sub 接口执行逐元素减法，最后将计算结果写回 GM。

采用 TQue 管理输入和输出缓冲区，保证数据搬运与计算流程正确。
