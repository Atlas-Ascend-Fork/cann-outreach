## 算子实现介绍

这个版本针对固定输入 (8, 2048) 做了专用优化，实现过程如下：
 1. 分核
    共 16384 个元素，使用 8 个核，每核连续处理 2048 个元素。
 2. 分配片上缓冲（UB）
    每个核分配一块连续 UB，划分为 xLocal、yLocal、zLocal 三部分。
 3. 搬入数据
    通过 DataCopy 将本核对应的 x、y 数据从全局内存搬到 UB，并等待搬运完成。
 4. 向量计算
    调用 AscendC::Sub，一次完成本核的逐元素减法：
 5. 写回结果
    等待计算完成，再将 zLocal 搬回输出张量对应的位置。
 主要优化点：固定形状后，省去了动态分块、除法、循环及尾块判断；每核只处理一块数据，用直接缓冲和必要的同步替代队列管理，减少了小算子的控制开销。float32 和  float16 共用模板实现。
