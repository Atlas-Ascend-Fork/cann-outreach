## 算子实现介绍

本实现基于 Ascend C 完成逐元素减法 z = x - y，支持 ND 格式、shape 为 (8, 2048) 的 float32 和 float16 输入。

采用 8 个 AIV 核并行计算，每核处理 2048 个元素，拆分为两个 1024 元素的数据块。主机端根据本次运行的实际输入地址间距，检查对齐和 16 位步长范围并构造二维 DMA 描述；向量运算及输出搬运描述也作为参数传入，以精简设备端设置指令。设备端分阶段加载、计算和写回，根据输入地址顺序保持 x-y 语义。

float16 路径在 UB 中复用输入缓冲区保存减法结果，并在被计时的算子内执行指令预取。各数据块使用显式事件同步，算子退出前等待输出搬运完成。输入地址间距不满足快速路径条件时回退到独立加载；其他长度及可用核数不足时使用常规分块处理。
