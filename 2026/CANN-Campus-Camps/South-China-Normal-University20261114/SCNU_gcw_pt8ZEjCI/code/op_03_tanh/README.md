## 算子实现介绍

本 Tanh 算子实现逐元素双曲正切计算，支持 fp16/bf16/fp32 数据类型。Tiling 策略上，采用动态多核切分，引入最小切分阈值避免小张量过度多核并行；对 blockFactor 与 ubFactor 严格按 32B 对齐，并精细规划 UB 空间（包含输入输出双缓冲及 fp32 临时空间），确保不超限。Kernel 侧进行了深度优化：1. 防溢出设计：将输入数据 Clamp 限制在 [-20, 20] 之间，并采用等效公式 tanh(x) = (exp(2x)-1)/(exp(2x)+1) 计算，不仅有效防止 exp 上溢导致的 NaN，还减少了一次 exp 指令开销；2. 精度保障：fp16/bf16 输入统一升精度至 fp32 计算后再降精度回写，有效避免半精度下的抵消误差；3. 边界处理：使用 DataCopyPad 处理尾块搬运，保证任意 Shape 下的泛化与鲁棒性。
