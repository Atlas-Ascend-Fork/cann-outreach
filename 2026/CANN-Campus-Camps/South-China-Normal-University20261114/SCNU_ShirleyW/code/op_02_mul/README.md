## 算子实现介绍

基于 Ascend C 实现矢量乘法算子 z = x * y，支持 float16 和 float32，输入输出形状为 (8, 2048)，数据格式为 ND。Host 侧完成输入形状和类型检查、输出形状和类型推导，并配置 Tiling 参数与 8 核并行启动。Kernel 侧根据总元素数和核数计算数据偏移，每核处理连续的 2048 个元素，使用 TBuf 分配本地缓冲区，一次完成输入搬运、矢量乘法计算和结果回写，通过 SetFlag/WaitFlag 保证各阶段的数据依赖，减少队列管理开销。搬运长度满足 32 字节对齐要求。
