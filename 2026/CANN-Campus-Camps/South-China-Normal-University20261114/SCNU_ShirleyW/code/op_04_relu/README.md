## 算子实现介绍

基于 Ascend C 实现 ReLU 激活算子 y = max(0, x)，支持 float16、float32，以及 (8, 2048)、(2048, 2048) 两种输入形状，数据格式为 ND。Host 侧检查输入形状和类型，根据可用核数及 UB 容量配置分块参数。小输入最多使用 8 核，每核通过固定缓冲区一次完成搬入、计算和回写，使用 SetFlag/WaitFlag 保证流水依赖。大输入最多使用 32 核，每次处理最多 8192 个元素，采用双缓冲队列预取下一块数据。Kernel 侧调用基础矢量指令 Relu 完成计算，数据搬运长度满足 32 字节对齐要求。
