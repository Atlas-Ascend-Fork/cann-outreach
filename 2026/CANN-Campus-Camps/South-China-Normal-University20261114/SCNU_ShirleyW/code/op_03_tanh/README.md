## 算子实现介绍

基于 Ascend C 基础算子组合实现 Tanh 激活函数，未调用 Tanh 高阶计算 API。支持 float16 和 float32，输入输出形状为 (8, 2048)，数据格式为 ND。Host 侧检查输入形状和类型，结合可用核数配置分块，通常使用 8 核并行，每核处理 2048 个元素，每次 UB 循环处理 512 个元素。Kernel 侧使用 Exp、Add、Sub、Div 等基础操作计算 (exp(x)-exp(-x))/(exp(x)+exp(-x))；float16 输入提升为 float32 计算后转换回原类型。通过限制指数输入范围避免溢出，并在零附近采用 x-x³/3 减少消减误差。使用队列和流水同步管理数据搬运与临时缓冲区复用。修改后已通过平台评测。
