## 算子实现介绍

采用 8 核并行实现矢量减法 z = x − y，支持 float16 和 float32。针对固定输入形状 (8, 2048)，将 16384 个元素均匀划分，每核处理 2048 个元素，无需尾块处理。

使用静态 LocalTensor 管理 UB，输入与输出缓冲区独立且地址满足 32B 对齐，省去 TPipe 和 InitBuffer 初始化开销。每核一次性搬入 x、y，通过显式指定掩码和重复次数的 Sub 接口完成计算，再一次性写回 z。使用 MTE2_V、V_MTE3 事件同步保证搬运与计算的数据依赖，内核结束前通过流水屏障等待执行完成。
