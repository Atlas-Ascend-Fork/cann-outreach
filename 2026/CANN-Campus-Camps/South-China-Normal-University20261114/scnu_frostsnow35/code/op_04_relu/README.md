## 算子实现介绍

算子实现：ReLU y = max(0, x)，支持 fp32/fp16、ND，形状 (8,2048) 和 (2048,2048)。

核心策略：

小输入 4 核。每核至少 4096 元素，16384 元素只开 4 个 AIV 核，避开多核启动开销；大输入按 AIV 核数满核切分。

UB 原地复用。ReLU 不保留输入，Maxs(local, local, 0, n) 直接覆盖，UB 从 4 块降为 2 块，单块 48KB 提升到 85KB，每核循环减半。

静态 Tensor。直接构造 Ping/Pong 两块 LocalTensor，不用 TPipe/TQue，省掉队列分配与同步。

tile 均分。按 tileCount 反算每块大小，去掉过小尾块，避免流水空转。

手动三级流水。MTE3_MTE2 到 MTE2 到 MTE2_V 到 V 到 V_MTE3 到 MTE3，Ping/Pong 交替；原地复用必须有 MTE3_MTE2，保证写回完成后才覆盖。

性能：初始 5.57 / 25.09 微秒，当前 4.06 / 19.52 微秒，平台最优 4.06 / 18.80 微秒。大输入降 22.2%，小输入相较过往版本最优。
