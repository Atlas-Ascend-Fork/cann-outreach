## 算子实现介绍

小张量：
    totalNum &gt; 0 且 &lt;= 16384，并且每核最大块能够一次放入 UB 时，
    使用独立 ReluSmall 类，保留 v4 的单次搬运/Relu/搬出及事件同步。
    TPipe 在核函数入口创建。该类不包含流式队列或运行时路径选择标志。
  大张量或小张量 UB 不足：
    使用原版 Relu 类，包含类内 TPipe、双缓冲队列和原版逐块循环。
    类定义与实现取自已交付 v1，大张量继续采用 32 KiB tile 上限。
