## 算子实现介绍

本次实验使用 Ascend C 编程语言实现了一个矢量减法算子，主要功能是对两个输入张量进行逐元素相减，计算公式为 \(z=x-y\)。根据题目要求，输入张量的形状为 (8, 2048)，支持 float32 和 float16 两种数据类型。
  在实现过程中，将输入数据分配给多个 AI Core 并行处理，每个核负责一部分数据，并将数据分成多个小块进行计算。具体分为三个步骤：
  1. 数据搬运：通过 DataCopy 将输入数据从全局内存搬运到片上内存，为后续计算做准备。
  2. 执行计算：调用 Ascend C 中的 Sub 函数，对两个输入数据进行逐元素相减，并保存计算结果。
  3. 结果写回：将片上内存中的计算结果通过 DataCopy 搬运回全局内存，得到最终输出。
  在 Host 端，根据输入张量的数据类型选择对应的核函数，分别处理 float32 和 float16 数据。通过多核并行和分块计算，完成整个张量的减法运算。
