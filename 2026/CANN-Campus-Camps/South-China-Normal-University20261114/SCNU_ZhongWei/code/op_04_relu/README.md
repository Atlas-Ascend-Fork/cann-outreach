## 算子实现介绍

整体思路：ReLU 是逐元素激活，输入输出同形状，支持 float32/float16。实现重点是多核负载均衡和搬运与计算重叠，而不是复杂算法。

Host 侧 Tiling：从平台获取可用 Vector Core 数和 UB 容量，决定启动核数。核间切分尽量均分数据，并对齐到 Cache Line 边界；不能整除时采用“前若干核处理大块、最后一个核处理尾块”的方式，把各核长度和单次 tile 长度写入 TilingData。核内 tile 长度按 UB 容量反推，保证地址和长度对齐。最后设置实际启动核数。

Kernel 侧：根据当前核索引和 TilingData 计算本核在 Global Memory 上的起始偏移，只读写自己负责的数据。使用 TPipe 管理 UB，输入输出队列深度取 1，循环执行 CopyIn、Compute、CopyOut：搬入一块数据，调用 ReLU 向量指令计算，再搬回 Global Memory。最后一次循环处理核内尾块。

DoubleBuffer：通过给输入输出队列各分配两个缓冲块开启，使下一块搬运与当前块计算重叠。开启后 tile 长度要相应减小，避免 UB 溢出。若 tile 太小，同步开销可能抵消收益，因此优先保证搬运块足够大、地址对齐。
