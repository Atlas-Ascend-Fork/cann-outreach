## 算子实现介绍

使用 Ascend C 实现逐元素 ReLU 激活 y=max(0,x)，支持 float32、float16，以及 (8,2048) 和 (2048,2048) 两种输入形状。Tiling 根据输入规模、可用核数和 UB 容量确定分块，单核起始地址和处理长度满足 32B 对齐要求，每个 Tile 最多处理 8192 个元素。输入、输出队列均采用双缓冲，并在处理当前 Tile 前预取下一 Tile。调用 AscendC::Relu 完成向量计算，最后将结果搬回 Global Memory；尾块按实际剩余元素数量处理，保证数据完整覆盖且不越界。
