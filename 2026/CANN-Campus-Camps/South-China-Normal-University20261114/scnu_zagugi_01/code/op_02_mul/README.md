## 算子实现介绍

本程序基于 Ascend C 实现矢量乘法算子，完成逐元素计算 z = x * y，支持形状为 (8, 2048) 的 float32 和 float16 张量。Host 侧负责输出形状与数据类型推导、Tiling 参数设置及核数配置，并通过模板参数选择对应的数据类型实现。Kernel 采用纯矢量核模式 AIV_ONLY，使用 8 个核并行计算，每核处理连续的 2048 个元素。计算时先将两路输入从全局内存（GM）搬入片上统一缓冲区（UB），调用 AscendC::Mul 执行乘法，再将结果写回 GM。实现中直接指定 UB 地址，省去 TPipe 和队列管理，并复用输入缓冲区保存乘法结果。数据搬运与矢量计算之间通过硬件事件显式同步，保证各阶段按照依赖顺序完成，以减少管理开销并确保计算正确。
