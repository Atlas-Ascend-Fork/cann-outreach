## 算子实现介绍

本程序基于 Ascend C 实现矢量减法算子，完成逐元素计算 z = x - y，支持形状为 (8, 2048) 的 float32 和 float16 张量。程序采用 8 核并行，每个核负责连续的 2048 个元素：首先将输入数据从全局内存（GM）搬入片上统一缓冲区（UB），然后调用 AscendC::Sub 执行矢量减法，最后将结果写回全局内存。实现中直接指定本地张量的 UB 地址，并复用输入 x 的缓冲区保存计算结果，省去独立输出缓冲区及队列管理。各阶段通过硬件事件显式同步，保证输入搬运、矢量计算和输出搬运按依赖顺序完成。主机侧根据输入数据类型选择对应的核函数实例，以适配两种精度的数据处理。
