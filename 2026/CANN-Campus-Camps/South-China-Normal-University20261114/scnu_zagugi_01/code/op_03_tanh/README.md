## 算子实现介绍

本程序基于 Ascend C 实现 Tanh 激活算子，完成逐元素计算 y = tanh(x)，支持形状为 (8, 2048)、数据类型为 float32 或 float16 的 ND 格式张量。Host 侧根据输入类型选择对应的核函数实例，其中 schMode=0 对应 half，`schMode=1` 对应 float，并设置 Tiling 参数及启动核数。Kernel 采用 8 核并行，每核一次处理连续的 2048 个元素：先将输入从全局内存（GM）搬入片上统一缓冲区（UB），再调用 AscendC::Tanh 完成计算，最后将结果写回 GM。计算过程使用独立的 UB 临时缓冲区，`float16` 输入的中间计算采用 float32，以降低精度损失；输入、输出队列负责数据搬运与计算之间的同步。通过每核整块处理，减少小块循环和重复队列操作的开销。
