## 算子实现介绍

采用 Ascend C 多核实现逐元素乘法 z = x * y，输入和输出均为 (8, 2048) 的 ND 张量，支持 float32 和 float16。
Host 侧以 128 个元素为一组，将连续数据分配给各矢量核，保证搬运满足 32 B 对齐。核数充足时，float32 使用 16 核，每核处理 1024 个元素，float16 使用 8 核，每核处理 2048 个元素。核内使用静态 UB 缓冲区，将 x 和 y 搬入后调用 AscendC::Mul，再将结果写回 z。常规配置下，每核只需执行一轮搬入、计算和写回。
