## 算子实现介绍

【Tiling策略】
采用动态自适应切分：根据全局元素总量与硬件最大核数，自动计算最优启动核数（useCoreNum）与单次循环因子（ubFactor）。严格按照256B对齐原则，完美兼容小Shape（8x2048）与大Shape（2048x2048）的负载均衡，自动处理尾块，无越界风险。
【Kernel流水线】
摒弃低效的手工Flag同步，采用标准 TPipe 与深度为2的 TQue 队列。利用 Ascend C 框架底层的原生机制实现完美的自动Double Buffer（Ping-Pong）流水线。实现 MTE2搬入、Vector计算与 MTE3搬出的极致并行，利用计算时间彻底掩盖数据搬运延迟。
【指令与架构优化】
    单指令计算：直击ReLU算子数学本质 y = max(x, 0)，直接调用 Maxs 基础向量指令，替代高阶API，大幅降低函数调用与解析开销。
    编译期派发：结合 TilingKey 机制与 constexpr 判断，在编译期完成 FP16/BF16 与 FP32 数据类型的模板特化，实现运行时零分支跳转，性能拉满。
