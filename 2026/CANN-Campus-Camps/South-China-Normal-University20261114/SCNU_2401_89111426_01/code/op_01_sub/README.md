## 算子实现介绍

采用 Ascend C 多核实现逐元素减法 z = x - y，支持 float16 和 float32。启动核数根据可用矢量核数确定，最多使用 8 核。
Tiling 按每块 128 个元素切分，(8, 2048) 的输入共划分为 128 块，各核处理连续的数据块。float16 和 float32 每块分别搬运 256 B 和 512 B，均满足 32 B 对齐。核内采用 UB 双缓冲，通过 DataCopy 搬入 x 和 y，调用 AscendC::Sub 计算，再将结果写回 z 的对应位置。
