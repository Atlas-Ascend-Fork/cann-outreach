## 算子实现介绍

本程序基于 Ascend C 实现 ReLU 激活算子，完成逐元素计算 y = max(0, x)，支持形状为 (8, 2048) 和 (2048, 2048)、数据类型为 float32 或 float16 的 ND 格式张量。Host 侧根据输入类型选择对应的核函数实例，并结合输入规模和硬件可用矢量核数量设置 Tiling 参数：小输入最多使用 8 核，大输入最多使用 32 核，各核处理连续且互不重叠的数据。Kernel 采用纯矢量核模式，通过 AscendC::Relu 完成计算。小输入每核整块处理，减少循环开销；大输入按每块最大 32KB 分块，采用双缓冲并预取下一块数据，为输入搬运、计算和输出搬运的重叠执行创造条件。输入、输出队列负责各阶段的同步与缓冲区复用，在保证数据依赖正确的同时提高处理效率。
