## 算子实现介绍

实现方案
采用多核并行实现 z = x * y，计算为逐元素相乘，不涉及跨元素累加。主机侧从平台获取 AIV 核数，按元素总数均分数据，单核内全部数据作为一个数据块处理，不设核内分块。启动核数需满足元素总数可被核数整除，且单核元素数为 32 字节对齐对应元素数的整数倍。输入形状为 8 * 2048、共 16384 个元素，float32 与 float16 下均启动 32 核，单核 512 个元素，各核起始地址偏移为单核长度乘以核序号。

UB 切分
x 与 y 共用一块 VECIN 缓冲区，容量为两个数据块，前段存放 x，后段存放 y，y 的偏移为一个数据块长度；z 使用独立的 VECOUT 缓冲区，缓冲区深度均为 1。数据块长度上限为 8192 个元素，超出时折半切分并保持 32 字节对齐；本形状单块长度为 512 个元素，float32 下 VECIN 占用 4096 字节、VECOUT 占用 2048 字节，float16 下分别为 2048 字节与 1024 字节。全部搬运长度为 32 字节的整数倍。

Tiling 策略
主机侧以数据类型对应的 32 字节对齐元素数为约束选择启动核数，将元素总数写入 tiling 结构体 length 字段，workspace 大小置为 0。数据类型通过 ASCENDC_TPL_SEL_PARAM 生成 TilingKey，kernel 侧按模板参数 DT_X 实例化为 float 与 half 两个版本。形状推导将第一个输入 x 的形状与数据类型直接赋给输出 z。

执行流程
本形状下单核仅执行一轮 CopyIn、Compute 与 CopyOut。CopyIn 通过两次 DataCopy 将 x 与 y 搬入 VECIN 缓冲区，触发 MTE2 到 V 的同步；Compute 调用 AscendC::Mul 完成逐元素相乘，结果写入 VECOUT 缓冲区，触发 V 到 MTE3 的同步；CopyOut 通过一次 DataCopy 将结果写回全局内存，随后释放缓冲区。
