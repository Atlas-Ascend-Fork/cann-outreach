## 算子实现介绍

采用 Ascend C 多核分块实现向量减法 z = x - y，支持 ND 格式的 float32 和 float16。

Tiling 策略：在 Host 侧根据输入形状计算总元素数，每个分片最多处理 2048 个元素，启动核数取可用核数与分片数量的较小值，各核按核编号轮转处理分片。

核内使用 TPipe 和双缓冲 TQue 管理 UB，依次完成数据搬入、AscendC::Sub 矢量减法和结果搬出，通过队列同步各阶段。分片起始地址及 UB 缓冲区按 32 字节对齐；对齐数据使用 DataCopy，非对齐尾片使用 DataCopyPad，仅搬运有效字节，避免越界。空张量直接返回。
