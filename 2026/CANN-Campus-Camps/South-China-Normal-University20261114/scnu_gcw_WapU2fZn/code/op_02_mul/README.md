## 算子实现介绍

本算子基于 Ascend C 实现逐元素乘法 `z = x × y`，面向昇腾 Ascend 910B 平台，支持形状为 `(8, 2048)`、ND 格式的 float16 和 float32 输入，输出形状及数据类型与输入保持一致。

Host 侧完成输出形状与数据类型推导，通过 Tiling 参数传递总元素个数，并配置启动核数。Kernel 侧将数据划分为每块 128 个元素，由各计算核按核编号循环分配数据块，依次执行数据搬入、乘法计算和结果搬出。计算过程使用 `AscendC::Mul` 接口，结合双缓冲队列完成缓冲区复用与阶段间同步，实现多核并行处理。
