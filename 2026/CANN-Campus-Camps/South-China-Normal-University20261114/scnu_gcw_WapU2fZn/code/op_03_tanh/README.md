## 算子实现介绍

本算子基于 Ascend C 实现逐元素双曲正切计算，支持 float32 和 float16 数据类型。Host 侧根据输入元素数量、可用计算核数量和 UB 容量确定核间分块及核内分块大小，并进行 32 字节对齐。Kernel 侧采用输入、输出双缓冲，分轮完成数据搬入、计算与结果搬出。计算时将 float16 数据转换为 float32，利用指数、加减和除法实现 tanh(x) = (exp(x) - exp(-x)) / (exp(x) + exp(-x))，最后转换回原数据类型。为避免指数溢出，将计算输入限制在 [-10, 10]，并对不足完整分块的尾部数据单独处理。
