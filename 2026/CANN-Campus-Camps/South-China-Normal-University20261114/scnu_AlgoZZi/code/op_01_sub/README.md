## 算子实现介绍

本算子使用 Ascend C 实现逐元素减法 z = x − y，支持 FP32 和 FP16 数据类型。Host 侧根据输入张量形状计算元素总数，将数据按每块 2048 个元素划分，并结合设备可用核数确定启动核数。各核按照核编号分配数据块，以核数为步长循环处理，实现多核并行计算。

核内通过 TPipe 和 TQue 管理 UB 缓冲区及数据同步，依次完成输入数据从 GM 搬入 UB、调用 AscendC::Sub 执行矢量减法、将结果从 UB 写回 GM。对于满足 32 字节对齐的数据块，使用 DataCopy 搬运；对于末尾不足一块且不满足对齐要求的数据，使用 DataCopyPad 处理，保证数据完整且不越界。当前实现已通过全部 2 个测试点，输出错误占比均为 0.00%。
