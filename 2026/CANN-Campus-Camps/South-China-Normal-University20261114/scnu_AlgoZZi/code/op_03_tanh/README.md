## 算子实现介绍

本算子基于 Ascend C 实现逐元素双曲正切函数 y = tanh(x)，支持 FP32 和 FP16 数据类型，采用多核并行和双缓冲机制处理输入数据。

Host 侧根据输入元素总数和设备可用矢量核数确定启动核数，将每核处理的元素数量按 32 字节对齐，并通过 Tiling 结构体传递总元素数、每核处理长度、UB 分块长度和临时缓冲大小。调用 GetTanhMaxMinTmpSize 查询 FP32 Tanh 计算所需的临时空间，结合输入输出双缓冲、类型转换缓冲及设备实际 UB 容量确定分块大小，避免超出可用空间。

Kernel 侧根据核编号确定输入输出的 GM 起始地址，通过 TPipe 和 TQue 管理数据搬运与同步，提前搬入下一块数据，使搬运与当前块的计算、写回交叠。计算调用 AscendC::Tanh；FP16 输入先转换为 FP32 完成中间计算，再将结果转换回 FP16。满足 32 字节对齐的数据使用 DataCopy 搬运，未对齐的尾块使用 DataCopyPad 处理，保证数据完整且不越界。
