## 算子实现介绍

本算子基于 Ascend C 编程语言原生开发，实现了逐元素矢量减法（z = x - y）。Host 侧通过动态获取硬件核数将数据均匀切分至各 AI Core，并依据数据类型（fp32/fp16）自动分发对应的模板实例；Kernel 侧采用 TPipe 与 TQue 进行片上内存管理及双缓冲机制，通过 CopyIn、Compute（调用 AscendC::Sub）、CopyOut 三步流水线完成计算，并针对核间及核内数据不均分的情况设计了完善的尾块处理与空核保护机制，确保了极端的边界安全性。
