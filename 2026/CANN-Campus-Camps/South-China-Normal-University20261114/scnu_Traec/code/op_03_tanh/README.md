## 算子实现介绍

**Tanh 算子实现介绍**

Tanh 是逐元素激活算子，对输入张量 x 中的每个元素独立计算双曲正切，输出张量 y 与 x 形状一致。本算子输入输出均为 (8, 2048) 的 ND 张量，支持 float32 与 float16 两种数据类型。实现上不直接调用 Tanh 接口，而是按公式 tanh (x) = (eˣ − e⁻ˣ) / (eˣ + e⁻ˣ)，用 Muls、Exp、Sub、Add、Div 等基础小算子拼接完成：先分别求出 eˣ 与 e⁻ˣ，再相减得到分子、相加得到分母，最后相除得到结果。Kernel 侧按 “搬入 — 计算 — 搬出” 三级流水组织，Host 侧完成多核与分块切分，中间结果通过 UB 临时缓冲保存。
