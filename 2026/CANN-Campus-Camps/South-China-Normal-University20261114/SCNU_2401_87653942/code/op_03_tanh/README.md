## 算子实现介绍

本算子基于 Ascend C 实现逐元素双曲正切运算 y = tanh(x)，支持 FP16 和 FP32 输入，输出的形状与数据类型与输入一致。

Kernel 侧使用 Abs、`Muls`、`Exp`、`Adds` 和 Div 等基础向量指令组合实现。先计算 e = exp(-2 × |x|)，再通过 (1 - e) / (1 + e) 得到结果的绝对值，最后恢复输入的符号。每个元素只需计算一次指数，且指数的输入始终非正，避免了直接计算 exp(x) 或 exp(-x) 时可能发生的上溢。FP16 输入先转换为 FP32 参与计算，最后再舍入回 FP16，以减少中间计算的舍入误差。

Host 侧根据输入元素数、可用 Vector 核数和 UB 容量进行分核与分片。各核处理连续的数据区间，并在同一核内复用输入、输出和临时缓冲区。对齐的数据使用 DataCopy 搬运，不足 32 字节对齐的尾部使用 DataCopyPad 按实际长度搬运，确保尾部元素参与计算并正确写回。
