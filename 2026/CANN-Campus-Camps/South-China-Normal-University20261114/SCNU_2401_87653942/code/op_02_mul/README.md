## 算子实现介绍

本算子基于 Ascend C 实现两个同形状 ND 张量的逐元素乘法 z = x * y，支持 FP16 和 FP32。Host 侧根据输入元素数、可用 AIV 核数和 UB 容量确定启动核数及每批处理长度。Device 侧按 32 字节块在各核之间分配数据，由最后一个核处理不足 32 字节的尾部。每核分批将输入从 GM 搬入 UB，调用 AscendC::Mul 计算，再将结果写回 GM。对齐数据使用 DataCopy，非对齐尾部使用 DataCopyPad 按实际有效长度搬运，避免整数切分丢失尾部元素。空输入直接返回，短输入也能按实际长度处理。
