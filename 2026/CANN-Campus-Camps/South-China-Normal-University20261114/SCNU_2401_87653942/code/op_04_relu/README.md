## 算子实现介绍

本算子基于 Ascend C 实现逐元素 ReLU 运算 y = max(0, x)，支持 FP16 和 FP32 的 ND 张量，输出形状和数据类型与输入一致。Kernel 使用 AscendC::Relu 对片上数据执行向量计算，保留正值，将负值置零。

Host 根据输入长度、可用 Vector 核数和 UB 容量分配任务。各核处理连续的数据区间，分核起点按 32 字节对齐。每核只需处理一片时使用单缓冲，多片时使用双缓冲，使相邻分片的搬运和计算可以重叠。对齐数据通过 DataCopy 搬运，非对齐尾部通过 DataCopyPad 按实际长度读写，确保有效元素全部参与计算。
