## 算子实现介绍

本算子使用 Ascend C 实现两个同形状张量的逐元素减法 z = x - y，提供 FP16 和 FP32 两种核函数实例。Host 侧根据输入形状计算总元素数，固定启动 8 个核。Device 侧将输入均分给各核，每核再处理 16 个等长数据块。每块通过 DataCopy 从全局内存（GM）搬入统一缓冲区（UB），调用 AscendC::Sub 完成减法，再将结果写回 GM。输入和输出队列各分配两个缓冲块。当前实现要求输入能按上述方式整除，且每块的搬运字节数满足 32 字节对齐。
