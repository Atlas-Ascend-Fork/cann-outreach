## 算子实现介绍

用单算子多核切分架构。Host侧计算 totalLength，平分为多个核处理。
Tiling与UB切分： 单核内采用 tileNum * BUFFER_NUM 的分块策略（双缓冲）。当前赛题给定总元素数为16384，单次处理长度设为128（fp32为512B，fp16为256B），完全满足UB切分按32B对齐的要求。
对齐策略： 当前Shape能被完美整除，但设计上预留了 totalLength 向上对齐到 BLOCK_SIZE（32B）的逻辑，保证在任意Shape下都不会发生内存越界（踩踏），确保数据搬运的安全性和计算的高效性。
