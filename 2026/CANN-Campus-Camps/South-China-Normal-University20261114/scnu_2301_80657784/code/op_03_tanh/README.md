## 算子实现介绍

使用 Ascend C 实现逐元素 Tanh 激活，支持 float32 和 float16。Tiling 根据输入元素数量、可用核数和 UB 容量确定核数、单核处理长度及 Tile 大小；单核数据长度按 32B 对齐，每个 Tile 最多处理 1024 个元素。计算采用 tanh(x)=2/(1+exp(-2x))-1，float16 输入先转换为 float32 进行中间运算，输出时再转换回原类型。将指数参数限制在 [-20,20]，避免较大输入导致指数溢出。输入、输出队列各配置两个 UB 缓冲区，按块完成数据搬入、计算和搬出。
