## 算子实现介绍

使用 Ascend C 实现逐元素减法 z = x - y，支持 float32 和 float16。采用多核并行，启动核数取不超过可用核数的最大 2 的幂，最多使用 8 个核，将输入数据均匀分配到各核。单核设置 tileNum=8、BUFFER_NUM=2，共循环处理 16 个数据块；使用 8 个核时，每块处理 128 个元素。通过 TPipe 和 TQue 管理 UB 缓冲区，依次完成数据搬入、AscendC::Sub 计算及结果搬出。两种数据类型的搬运长度均满足 32B 对齐要求。
