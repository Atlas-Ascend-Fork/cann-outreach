## 算子实现介绍

使用 Ascend C 实现逐元素乘法 z = x * y，支持 float32 和 float16。Host 侧完成输出形状和数据类型推导，并根据输入数据类型选择对应的核函数模板。最多使用 8 个核，将输入数据均匀分配到各核；单核以 256 个元素为一个 Tile 循环处理。使用单缓冲输入、输出队列管理 UB 数据，通过 DataCopy 搬入两个输入，调用 AscendC::Mul 完成乘法，再将结果搬回 Global Memory。每个 Tile 的搬运长度满足 32B 对齐要求。
