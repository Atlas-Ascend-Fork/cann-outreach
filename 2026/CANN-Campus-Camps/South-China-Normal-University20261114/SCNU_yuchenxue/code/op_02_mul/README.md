## 算子实现介绍

本算子基于 Ascend C 自定义算子工程实现逐元素乘法 z=x*y，输入输出形状均为 (8,2048)，支持 float16、float32 和 ND 格式。

Host 侧完成算子注册、形状推导、数据类型推导及 Tiling 计算，检查两路输入的形状和类型一致，并将总元素数、分块参数传递给 Kernel。根据设备可用核数，在 1、2、4、8 核中选择合适的启动数量，各核负责独立的数据区间。

Kernel 采用 CopyIn → Compute → CopyOut 流程：将两路输入从全局内存搬入片上缓冲，调用 AscendC::Mul 完成矢量乘法，再将结果写回全局内存。使用 TPipe、TQue 和 LocalTensor 管理缓冲分配、数据同步与资源回收，实现完整的数据覆盖。
