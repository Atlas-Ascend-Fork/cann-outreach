## 算子实现介绍

本算子基于 Ascend C 实现逐元素矢量减法 z = x - y。输入为两个形状均为 (8, 2048) 的 ND 格式张量，支持 float16 和 float32，输出与输入保持相同的形状和数据类型。

实现采用多核并行与分块处理。主机端计算输入的总元素数，并根据数据类型选择 half 或 float 核函数。共使用 8 个核处理 16384 个元素，每个核负责连续的 2048 个元素；每核执行 16 次循环，每次处理 128 个元素，各核处理范围互不重叠。

每次循环包含三个步骤：
1. 数据搬入：通过 AscendC::DataCopy 将当前分块的 x、y 数据从全局内存搬入片上缓冲区。
2. 减法计算：调用 AscendC::Sub(zLocal, xLocal, yLocal, tileLength)，完成当前分块的逐元素减法。
3. 结果搬出：将计算结果复制到输出张量 z 的对应位置，并释放局部张量以复用缓冲区。
算子通过 TPipe 和 TQue 管理缓冲区及数据依赖。针对题目指定形状，所有分块均满足 32 字节搬运对齐要求，无需额外处理尾部数据。
