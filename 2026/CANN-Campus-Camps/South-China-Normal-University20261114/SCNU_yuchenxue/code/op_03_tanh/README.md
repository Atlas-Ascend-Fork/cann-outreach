## 算子实现介绍

本算子基于开源仓工程模板实现 y=tanh(x)，输入输出形状均为 (8,2048)，支持 float16、float32 和 ND 格式。Host 侧完成形状检查、类型分派和多核分块，同时检查输入输出缓冲与临时张量的总占用是否超过设备 UB 容量。

计算采用有界指数形式：先计算 e=exp(-2*abs(x))，再计算幅值 (1-e)/(1+e)，最后恢复输入符号。符号因子使用 x/max(abs(x),1e-12)，避免零输入产生除零问题。指数输入始终非正，可避免直接计算正指数造成的溢出。

Kernel 使用四个 float32 临时张量保存中间结果。float16 输入先转换为 float32，完成计算后再舍入回原类型，以降低中间运算的精度损失。各阶段通过队列和向量流水同步保证依赖顺序，最终将结果写回输出张量。
