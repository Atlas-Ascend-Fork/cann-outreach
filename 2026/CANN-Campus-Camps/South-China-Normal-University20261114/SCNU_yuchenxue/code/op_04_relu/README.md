## 算子实现介绍

本算子基于 Ascend C 实现 ReLU 激活函数 \(y=\max(0,x)\)，支持 float16、float32 数据类型及题目规定的两种输入形状。Host 端根据输入规模、可用计算核数和片上内存（UB）容量确定分块方案，保证数据完整覆盖与搬运对齐，并提前计算每核处理长度和分块长度，减少核函数中的运行时计算。

小规模输入最多使用 8 个核，每核将数据一次搬入 UB，在同一缓冲区内完成 ReLU 运算后写回，通过同步事件保证搬运与计算的执行顺序，减少队列管理和循环开销。大规模输入最多使用 32 个核，各核处理独立的连续数据区间，采用输入、输出双缓冲队列，支持数据搬运与向量计算流水执行，提高并行处理效率。
