## 算子实现介绍

本算子基于 Ascend C 实现矢量减法，计算公式为 z = x - y，对输入张量对应位置的元素执行减法运算。输入 x、y 和输出 z 的形状均为 (8, 2048)，数据格式为 ND，支持 float32 和 float16 两种数据类型，输入输出数据类型保持一致。
Tiling 策略：将张量视为包含 16384 个元素的一维连续数据，按每块 2048 个元素划分为 8 个数据块。根据设备可用核心数，最多启动 8 个 Vector 核，各核心按照核编号及总核数分配数据块；当可用核心数少于 8 时，由同一核心循环处理多个数据块。每块数据在 float32 和 float16 下分别占用 8192 字节和 4096 字节，均满足 32 字节对齐要求。
核函数采用 CopyIn、Compute、CopyOut 三阶段实现。使用 TPipe 和 TQue 管理 UB 缓冲区及流水同步，先通过 DataCopy 将 x、y 的数据块从 GM 搬入 UB，再调用 AscendC::Sub 完成逐元素减法，最后通过 DataCopy 将结果写回 GM。Host 侧根据输入 dtype 选择 float 或 half 类型的核函数，并在指定的 stream 上启动执行。
