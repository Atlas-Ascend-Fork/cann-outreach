## 算子实现介绍

数据切分：16384 个元素分给 8 个核，每核处理 2048 个元素，再分成两块，每块 1024 个元素。
搬运与计算：先预取两块输入到 UB，再依次执行 Exp 和输出搬运，通过独立事件同步，让不同块的搬运与计算重叠。输入、输出使用独立 UB 区域，避免覆盖。
计算指令：直接调用 AscendC::Exp，底层使用硬件 VEXP；float32 每块执行 16 次向量重复，float16 每块执行 8 次。
优化方式：针对固定形状，固定分块、mask 和步长，去掉 TPipe/TQue 管理及 Kernel 中的 tiling 读取，结束前等待全部流水完成。
