------------------------------------------------------------------------------
[1] 核函数数据流复刻（严格按 PR #4319 的 5 处 TODO 语义）
------------------------------------------------------------------------------
  L1→L0A/L0B : A[:, k*64:(k+1)*64] / B[k*64:(k+1)*64, :]  （K 分 4 片）
  L0C 累加   : 第 1 片 init_c=True（覆盖），其后 3 片 init_c=False（累加）
  SPLIT_M    : AIV0 取行 0..127，AIV1 取行 128..255
  每 AIV     : 2 个 64 行 X 分片；Add → ReLU（**在加之后**）→ 原位写回 gm_y
  复刻完成，输出张量形状 = (256, 256)

------------------------------------------------------------------------------
[2] 与官方 PyTorch 参考解比对（容差公式与官方脚本逐字一致）
------------------------------------------------------------------------------
  tolerance = max(1, |expected|) / 256        （与官方脚本同一公式）
  超差元素数                = 0 / 65536
  最大绝对误差 max|diff|    = 1.33514e-05
  容差下界 1/256           = 0.00390625
  输出全非负（ReLU 生效）  = True

  反向对照   : 若误写成 ReLU(A@B)+X（先 ReLU 后 Add），超差元素 = 35006
               （应 > 0；>0 说明本判据能识别 ReLU/Add 顺序错误）
