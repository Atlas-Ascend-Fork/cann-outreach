## 算子实现介绍

这份代码实现了一个基于 Ascend C 的逐元素减法算子，用于计算两个张量对应元素的差，即 `z[i] = x[i] - y[i]`。Host 侧先根据输入张量的形状计算总元素数，再根据数据类型选择 FP16 或 FP32 核函数，并固定启动 8 个核并行处理。每个核负责一段数据，并将其进一步划分为 16 个小块，每个小块依次经过数据搬入、向量减法计算和结果搬出三个阶段，核心计算由 `AscendC::Sub` 完成，同时通过队列和双缓冲机制组织数据流转，为搬运与计算的流水重叠提供条件。该实现适用于形状和类型一致、连续存储的张量，目前没有广播、输入校验和尾块处理逻辑，因此使用时需要保证数据长度满足切分及搬运对齐要求；此外，代码尚未实现 BF16 分支，也没有根据传入的可用核数动态调整并行规模。
